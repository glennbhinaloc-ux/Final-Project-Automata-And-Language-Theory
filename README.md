# Gender Neutral Language Recognizer

A command-line app that finds predefined gender-specific terms in a .txt file
using regular expressions and suggests gender-neutral alternatives.

## Requirements
- Python 3.8 or newer
- No external libraries (uses only `re`, `os`, and `sys` from the standard library)
